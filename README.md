#  Space Explorer

A modern and responsive JavaScript web application for exploring the Solar System.

Users can browse planets, search by name, save favorites using Local Storage, switch between dark and light mode, and discover interesting space facts.

##  Features

-  Explore all eight planets of the Solar System
-  Search planets instantly
-  Add and remove favorite planets
-  Favorites saved with Local Storage
-  Learn More modal with detailed planet information
-  Dark / Light mode
-  Fully responsive design
-  Interactive Space Facts section
-  Modern glassmorphism UI
-  Smooth animations

##  Getting Started

1. Clone the repository

```bash
git clone https://github.com/yourusername/space-explorer.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No installation or build tools are required.
